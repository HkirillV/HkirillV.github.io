Button

Buttons trigger an action or navigation. Import them from @atlas/button, versioned as a package and shipped across all 9 internal products.

Variants

Style
Size

Usage

Use primary for the single most important action on a screen, secondary for supporting actions beside it, and ghost for low-emphasis actions inside dense UI like tables and toolbars. 

// usage
<Button variant="primary" size="md">
  Save changes
</Button>

Props

PropTypeDescription
variant'primary' | 'secondary' | 'ghost'Visual style and emphasis level.
size'sm' | 'md' | 'lg'Controls height and horizontal padding.
disabledbooleanPrevents interaction and dims the button.
loadingbooleanShows a spinner and disables the button.

Accessibility

  • Renders a native <button>, so keyboard and screen-reader behaviour come for free.
  • Focus ring meets WCAG 2.2 non-text contrast against every surface token.
  • loading sets aria-busy and keeps the label readable.
